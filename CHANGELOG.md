# Histórico

## 0.1.0 — 2026-09-21

- Primeira versão local com Laravel, Inertia, Vue, TypeScript e SQLite.
- Cadastro, edição, consulta e listagem com filtros e paginação.
- Atribuição manual e automática com proteção de concorrência.
- Interface responsiva, dados demonstrativos e validação em português.
- Testes, CI e documentação de arquitetura e colaboração com IA.
- Publicação no GitHub e autenticação ficam fora desta entrega local.

## 0.2.0 — 2026-09-22

- Publicação do código no GitHub e CI validada com SQLite/PostgreSQL 17 e PHP 8.3/8.4.
- Testes Chromium desktop/celular e smoke da imagem Docker de produção.
- Estrutura Workers + Containers e CD manual após checks.
- Supabase inicializado por TLS em schema dedicado; segredos no environment production.
- Guia de deploy, limitações e evidências atualizados.
